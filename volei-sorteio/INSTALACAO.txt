REGRA DE FORMAÇÃO DAS EQUIPES
- Pote A: ordem do maior peso para o menor.
- Pote B: ordem do menor peso para o maior.
- O primeiro do Pote A forma dupla com o primeiro do Pote B.
- O segundo forma dupla com o segundo, e assim sucessivamente.
- Depois da formação equilibrada, as equipes são embaralhadas para ocupar o chaveamento.

EXEMPLO
Jogador A = 10 e Jogador B = 5: equipe total 15.
Jogador A2 = 7 e Jogador B2 = 8: equipe total 15.

INSTALAÇÃO DO BACKEND
1. Abra a Planilha Google.
2. Acesse Extensões > Apps Script.
3. Substitua o arquivo Code.gs pelo conteúdo de apps-script/Code.gs.
4. Crie um novo arquivo de script chamado Automacao e cole apps-script/Automacao.gs.
5. Abra Configurações do projeto e marque a opção para exibir o arquivo de manifesto.
6. Substitua appsscript.json pelo conteúdo do repositório.
7. Execute a função INSTALAR_SISTEMA_COMPLETO.
8. Autorize o projeto.
9. Copie a ADMIN_KEY exibida no Registro de execução.
10. Implante como Aplicativo da Web:
    - Executar como: você.
    - Quem pode acessar: qualquer pessoa.
11. Copie a URL terminada em /exec.
12. Execute CONFIGURAR_URL_WEB_APP('SUA_URL_EXEC').
13. No GitHub, abra volei-sorteio/config.js:
    - API_BASE: cole a URL /exec.
    - DEMO_MODE: altere para false.

ACIONADOR AUTOMÁTICO
INSTALAR_SISTEMA_COMPLETO cria um acionador que executa a cada minuto.
Esse acionador conclui o sorteio mesmo que nenhuma pessoa mantenha a página aberta.

TELEGRAM
No editor, execute:
CONFIGURAR_TELEGRAM('TOKEN_DO_BOT', '@CANAL_OU_CHAT_ID')

Depois execute:
CONFIGURAR_URL_WEB_APP('SUA_URL_EXEC')

O sistema enviará:
- código de seis dígitos;
- botão Ativar sorteio;
- botão Abrir página pública.

WHATSAPP CLOUD API
No editor, execute:
CONFIGURAR_WHATSAPP(
  'TOKEN_META',
  'PHONE_NUMBER_ID',
  '5511999999999',
  'TOKEN_DE_VERIFICACAO',
  'v23.0'
)

Na aplicação da Meta:
- URL de callback: a URL /exec do Apps Script;
- token de verificação: o mesmo informado em CONFIGURAR_WHATSAPP;
- assine o campo messages.

ATIVAÇÃO
- Pelo painel: informe o código de seis dígitos.
- Pelo Telegram: clique no botão Ativar sorteio.
- Pelo WhatsApp: clique no botão interativo Ativar sorteio.
- A contagem regressiva será de 10 minutos.
- No fim, as equipes e o chaveamento serão publicados automaticamente.

RESULTADOS
No painel administrativo:
1. Abra Resultados e avanço no chaveamento.
2. Clique na equipe vencedora de cada jogo.
3. O vencedor avançará automaticamente.
4. Ao concluir a final, o painel exibirá a equipe campeã.

- Nunca grave ADMIN_KEY ou tokens no GitHub.

- A chave administrativa fica apenas na sessão do navegador quando usada no painel.
